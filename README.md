# Sender Pro

Sender Pro by Fasters Connect.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/6875fa0b83149c6d2b818ec7/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **Sender Pro** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/6875fa0b83149c6d2b818ec7/releases/latest) and reinstall.
